# 【企業規章 03】企業資訊安全與辦公設備守則

**文件編號**：IT-REG-2026-03  
**生效日期**：2026 年 1 月 1 日  
**權責單位**：資訊技術處 (IT Division) / 資訊安全委員會  

---

## 第一章 辦公設備配發與保管責任

### 1.1 公務筆記型電腦保管規範
1. 公司配發之筆記型電腦、充電器及轉接線，所有權屬公司所有，同仁應負善良管理人之保管注意義務。
2. 離開座位超過 5 分鐘以上，應隨手按下快速鍵鎖定螢幕（Windows: `Win + L` / Mac: `Cmd + Ctrl + Q`）。
3. 嚴禁在無人看管之公共場合（如高鐵車廂、咖啡廳、計程車）將筆電置於桌面無人看守。

### 1.2 設備遺失或損壞緊急應變通報
若公務筆電、公司手機或門禁識別證不幸遺失或遭竊，同仁應立即啟動以下 **緊急 3 步處置**：
1. **即刻通報 IT 資安熱線**：於 **30 分鐘內** 致電 IT 內部專線（分機 8888）或發送緊急信件至 `security-alert@example.com`。
2. **遠端帳號停權與資料抹除**：IT 部門將即時透過 MDM 系統鎖定該設備並強制登出所有 Google Workspace / Slack 企業帳號。
3. **報警與備案**：於 24 小時內前往鄰近警察局取得「受理案件證明單（報案三聯單）」，並將副本繳交總務處備查。

## 第二章 帳號、密碼與多因素驗證 (MFA)

### 2.1 企業密碼設定安全強度標準
1. 企業內部所有系統密碼長度至少為 **12 個字元** 以上。
2. 密碼組成必須同時包含以下 4 類字元中的至少 3 類：
   * 大寫英文字母 (A-Z)
   * 小寫英文字母 (a-z)
   * 阿拉伯數字 (0-9)
   * 特殊符號（如 `@`, `#`, `$`, `%`, `!`）
3. 系統將於 **每 90 天** 強制提示同仁變更密碼，且不得重複使用前 3 次曾設定過之密碼。

### 2.2 多因素驗證（MFA）強制規範
所有員工登入企業 Google 帳號、VPN 或 GitHub 企業組織時，必須全面啟用多因素驗證（Google Authenticator 或硬體 FIDO2 密鑰）。嚴禁將驗證碼轉傳他人。

## 第三章 外部儲存媒體與網路傳輸禁令

### 3.1 隨身碟（USB）與外接硬碟存取限制
1. 為防範勒索軟體與客戶商業機密外流，公司所有公務電腦之 USB 接口預設**全面禁用「寫入」功能（唯讀模式）**。
2. 同仁如因業務展覽、投標需要拷貝檔案至外部隨身碟，須至 IT 服務台提出「USB 存取權限暫時放行申請單」，審核通過後單次放行時效最長為 72 小時。
3. 嚴禁使用私人未經加密之隨身碟拷貝原始碼、客戶名冊或財務數據。

### 3.2 外部免費雲端硬碟使用限制
禁止將任何標註為「機密（Confidential）」之公司文件、合約、原始碼上傳至個人私人 Google Drive、Dropbox 或 Mega。內部公務分享一律使用公司企業版 Google Shared Drives。

## 第四章 第三方軟體安裝與開源授權

### 4.1 軟體自行安裝授權原則
1. 嚴禁在公務電腦安裝盜版、破解版軟體（如 P2P 下載軟體、BT、免光碟破解器）。
2. 開發人員安裝常見開源開發工具（如 VS Code、Node.js、Python、Git、Docker）可自由下載官方版本。
3. 若需採購商業付費軟體（如 Adobe CC、JetBrains、Figma 付費授權），應於每季初填寫「軟體資產增購申請單」經主管核准後由 IT 統一採購派發。
