1-1 核心思維

什麼是 Google Antigravity 2.0？

不是普通的聊天機器人，而是具備「自主行動能力（Agency）」的專屬工程師伴侶

❌ 過去傳統軟體開發模式
  • 學習門檻極高： 必須先花數個月死背 HTML、CSS、JS 語法。
  • 介面複雜令人窒息： 一打開就是成百上千行的代碼與複雜檔案樹。
  • 除錯痛苦耗時： 漏掉一個分號或引號，就要在網上查 2 個小時。
  • 手動繁瑣配置： 安裝各種套件、設定編譯環境常讓人放棄。
🚀 Antigravity 2.0 代理開發革命
  • 以對話為中心： 核心畫布直接擺在畫面正中央，用說的就能做網頁！
  • 支援自然語言與語音： 支援文字對話與 Ctrl + M 麥克風即時語音溝通。
  • 具備自主實作能力： 自動在指定資料夾建檔、修復代碼、生成圖片與部署。
  • 初學者角色轉變： 你不再是辛苦的碼農，而是發號施令的「產品經理（PM）」！
1-2 軟體安裝

下載、安裝與 Google 帳號授權

官方獨立桌面應用程式，跨平台支援 Windows 與 macOS

📦 步驟 1：取得官方安裝程式
官方下載入口：antigravity.google/download
  • Windows 平台： 下載 Antigravity-x64.exe，支援 Windows 10/11 64 位元系統。
  • macOS 平台： 下載 Antigravity.dmg，通用支援 Apple Silicon (M1/M2/M3/M4) 及 Intel 處理器。
🔑 步驟 2：登入與啟動主畫面
  • 按兩下安裝檔案，依循畫面指引 30 秒完成安裝。
  • 首次啟動點擊「Sign in with Google」，綁定個人 Google 帳號授權。
  • 授權成功後直接進入暗色科技風格主視窗，無需填寫繁雜個資！
💡 建議使用長期自有的個人 Gmail 帳號登入，以利未來長期保存專案與設定。

1-3 工作區觀念

為什麼我們需要「Project（專案工作區）」？

AI 是具備強大行動力的代理人，必須為它劃定專屬的「安全防護罩」

💡 核心觀念：AI 的專屬安全工作室

如果沒有指定工作區，AI 就不知道該在哪裡存檔，甚至可能不小心改動到你電腦裡的其他重要文件！

Project 就像是替 AI 劃定的一間專屬工作室：
它只被授權在這個特定資料夾內建造網頁、放置素材，絕對不會碰觸到工作室外面的任何私人資料。

黃金法則： 一個獨立網站/專案 ➔ 建立一個專屬乾淨資料夾！
🛠️ 建立 Project 三步驟口訣
  • 步驟 1：點擊左側 📁+ 圖示
    在左側導覽欄點選「New Project（新增專案）」。
  • 步驟 2：點選「Add Folder」挑選目標資料夾
    選擇電腦裡事先建好的空白資料夾（例如 C:\Antigravity\web-demo）。
  • 步驟 3：確認模式為 💻 Local 本機模式
    中央對話框下方維持 Local，代表 AI 會直接於該本機資料夾中工作！

工作區安全邊界與兩種綁定模式

隔離外界干擾，守護作業系統與私人檔案的絕對安全

📁 模式 A：單一資料夾專案（初學最推薦 ★★★★★）

1-4 權限管理

權限管理：我們到底授權給 AI 什麼能力？

知己知彼！理解 Antigravity 四大核心工具權限

📖 1. 讀取權限
Read Tools

允許 AI 掃描專案目錄、查看檔案內容，理解你現有的代碼結構。完全不具破壞性。

✍️ 2. 寫入修改
Write & Edit Tools

允許 AI 在專案資料夾內建立新檔案、更新文字或替換代碼片段，替你落實想法。

💻 3. 終端機指令
Terminal Command

允許在系統終端機執行指令（例如 Git 提交、安裝套件、發布網站）。安全核心控管區！

🌐 4. 網路與外掛
Web & MCP Tools

允許搜尋官方最新技術文檔、啟動瀏覽器自動化測試（/browser）或呼叫外掛工具。

1-4 模式切換

手動審查模式 vs. 自動同意模式

安全可控與開發效率的最佳平衡點

👤 預設安全審查（Default / Request Review）
  • 運作方式： 每次執行終端機命令前，跳出 Approve / Reject 按鈕等你核准。
  • 適合場景： 初學入門、重要正式環境、想要一步步觀察 AI 動作時。
⚡ 自動同意模式（Always Proceed / Unrestricted）
  • 運作方式： 自動放行所有檔案修改與指令，一口氣跑完一整串工作流！
  • 適合場景： 本課程的產品網頁製作、快速原型驗證，極度省時流暢。
📍 切換途徑：中央輸入框下方 Permissions 選單 或左側 Settings。
1-4 資安警示

課堂必背：學員三大資安守則

在享受 AI 強大威力的同時，養成優秀工程師的良好安全習慣

🚨 守則一：禁綁系統根目錄

絕對不要將個人的整顆硬碟根目錄（如 C:\）或「Windows 桌面」直接選為專案資料夾！

請永遠為每個網頁開立一個乾淨獨立的子資料夾（如 C:\Antigravity\my-site）。

🔐 守則二：禁放帳密機密檔案

專案資料夾內切勿放置任何私人密碼記事本、私鑰、身分證照片。

因為後續第 3、4 章我們會將專案推送到全世界都能看到的公開網路（GitHub Pages）上！

💡 守則三：善用 .gitignore 清單

若專案真的有私密金鑰（如 .env），直接吩咐 AI：

「幫我建立 .gitignore 把私密金鑰排除不要上傳」

它就像是門口的「請勿搬運清單」，上傳時自動跳過，安全留於本機！
