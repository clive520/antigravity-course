9-1 邊緣加速原理

傳統單點主機 vs. Anycast 全球邊緣就近路由

為什麼把網站從 GitHub Pages 升級到 Cloudflare Pages 會快上好幾倍？

🐌
傳統單點主機（含一般 GitHub Pages）
  • 地理距離限制：主機通常架設在美國西岸（如奧勒岡）或東京。
  • 高跨海延遲：台灣使用者請求必須跨太平洋光纖，單程延遲 150ms ~ 250ms。
  • 單點故障風險：如果該機房進行維護或線路被挖斷，全球網站同時癱瘓。
  • 流量計費昂貴：傳統雲端大廠（如 AWS、GCP）依出站 GB 計費，爆流量就是爆帳單。
🚀
Cloudflare 全球 Anycast 邊緣網路
  • 同一個 IP，全球 330+ 城市同時接聽：所有機房共用同一個 IP 位址。
  • 毫秒就近抵達：台灣訪客由台北或高雄內湖機房直接回應，延遲僅 5ms ~ 10ms！
  • 強大容錯與自動轉向：任一機房異常，流量於 1 秒內自動繞道至最近節點。
  • 無限頻寬免費保障：完全免收靜態檔案的出站下載流量費，安心上線。

支柱 2 · 運算大腦

Cloudflare Workers：邊緣無伺服器計算（Serverless）

不用租用主機，直接在全球 330+ 邊緣機房執行輕量後端程式碼

⚡
0 毫秒冷啟動

傳統 AWS Lambda 使用 Docker 容器，啟動需等 200ms ~ 2 秒。Workers 採用 Google Chrome V8 Isolates 沙盒隔離技術，啟動時間近乎 0 毫秒，反應極速！

🔒
安全環境變數（Secrets）

所有機密金鑰（Google Gemini API Key、Supabase Service Role Key）存放在 Workers 加密環境變數中，金鑰不落地，瀏覽器前端完全窺探不到！

🎁
免費 10 萬次 / 天

免費方案每日享有 100,000 次執行額度！每次請求提供 10ms CPU 執行時間（等待 AI API 或資料庫連線的網路 I/O 時間完全不計入）。

🧠 Workers 在我們 AI 知識庫系統中做什麼？

它是整個系統的「大腦總指揮」：接收新人問題 ➔ 呼叫 Embedding API 轉向量 ➔ 去 Supabase 撈取相關章節 ➔ 組裝防幻覺提示詞 ➔ 調用 LLM 生成答案並回傳前端！

Wrangler 是什麼？掌控 Cloudflare 艦隊的總司令

不用開網頁點滑鼠，直接在終端機操控全球所有邊緣運算與資料庫！

🤠
有趣的命名由來：「牛仔 / 馴馬師」

"Wrangler" 在英文原意是「牛仔、牧馬人 / 馴馬師」（專門馴服並管理狂奔的野馬群）。

Cloudflare 取這個名字的深刻寓意是：「用這套命令列工具，幫你輕鬆馴服並駕馭分散在全球 330 多個城市的邊緣伺服器與龐大微服務！」

🤖
為什麼讓 AntiGravity 掌握 Wrangler？

如果沒有 Wrangler，建立一個 AI 專案必須手動在後台開網頁、點擊建 Pages、建 Workers、建 D1、填寫密鑰...點擊數十次容易出錯。

有了 Wrangler，你只要動口吩咐：「AntiGravity，請幫我把當前目錄發布到 Pages，並設定好 Gemini 金鑰！」——AI 就能在命令列秒級全自動搞定！

架構思考 · 資安選型

方式 A 瀏覽器登入 vs. 方式 B API Token：控制內容一樣嗎？

日常操作看似相同，但在「權限大小、生效範圍與安全邊界」上有重大差別！

比較維度 方式 A：瀏覽器登入 (wrangler login) 方式 B：API Token 權杖 (.env)
比喻與概念 萬能金鑰（代理你整個帳號人格） 特定門禁卡（最小權限原則）
權限範圍 全開！擁有全帳號所有權限（含改 DNS、防火牆與帳單） 精確受控！只賦予被勾選的 Workers/Pages 權限
生效範圍 全域生效（儲存於電腦本機目錄，整台電腦專案共用） 單一專案隔離（存於該專案 .env，專案間互不污染）
生命週期與安全 長期有效，透過 Refresh Token 自動續期 可自訂到期日（如 30 天失效），可限定來源 IP，隨時單獨刪除
最佳適用場景 個人本機日常開發快速上手 交給 AI 代理自動化、團隊協同開發、CI/CD 正式上線
個人練習選方式 A · 正式專案與 AI 自動化堅決選方式 B 09 / 14

支柱 4 · 物件儲存

Cloudflare R2：終結雲端天價帳單的「零流量費」檔案庫

全面相容 AWS S3 API，大容量手冊 PDF、商品圖片與影片串流的最佳歸宿

💸
傳統 AWS S3 的隱形陷阱：出站流量費

AWS S3 雖然放檔案便宜，但只要有人下載，每 GB 都要收取高昂的出站傳輸費（Egress Fee）！若網站被爬蟲狂抓或忽然爆紅，月底常會收到數千甚至數萬元的恐怖帳單。

🛡️
Cloudflare R2：出站流量永遠 $0 元

R2 最大特色就是「永久零出站流量費（Zero Egress Fees）」！無論你的檔案被下載 1 次還是 100 萬次，出站流量費通通都是 0 元！

🎁 R2 免費方案配額：
每月提供 10 GB 儲存空間 · 100 萬次 Class A 寫入請求 · 1000 萬次 Class B 讀取請求！
AWS S3 完美替代方案

Cloudflare Zero Trust Access：免寫程式碼的員工登入防護牆

手冊含有內部差勤與報銷機密，如何不寫 Code 就能阻擋外人窺探？

✨
Cloudflare 做法

在 Cloudflare 後台點幾下，為 Pages 網站掛上一道邊緣身分防護牆（Zero Trust Access），完全不需改動任何前端 HTML 程式碼！

🎁
前 50 人永久免費

支援 Email OTP（拋棄式驗證碼）或 Google Workspace / Microsoft 365 企業網域登入，中小企業團隊免費享有頂級資安。
