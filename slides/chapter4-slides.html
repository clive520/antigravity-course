為什麼需要 GitHub CLI (gh 指令)？

GitHub 官方打造的終端機神兵利器，讓網頁操作完全被自然語言抽象化

  • AI 代理直接接管： 你連指令都不用記！ 對話說一句話，AI 自動在背景跑完全程
  • 10 秒極速上線： 泡一杯茶的時間，全球專屬網址已產出！

4-2 動口安裝

動口不動手：下指令請 Antigravity 安裝 GitHub CLI

不用到官網找下載頁面，複製提示詞交給 AI 自動處理系統套件安裝

💬 提示詞：請 AI 自動安裝 GitHub CLI（直接複製貼上）

"Antigravity，請先幫我檢查我的電腦目前有沒有安裝 GitHub CLI（gh 指令）。如果還沒有安裝，請幫我執行系統指令安裝它（Windows 透過 winget，macOS 透過 brew），並確認是否能正常讀取版本號！"

🤖 AI 背景執行 3 大動作
  • 動作 1：檢查現有版本
    gh --version
  • 動作 2：自動執行系統套件安裝指令
    Windows: winget install --id GitHub.cli
    macOS: brew install gh
  • 動作 3：驗證回報成功訊息
    在對話框向你回報已就緒，學員完全不用手動敲指令！
4-3 安全機制

關鍵解密：Antigravity 是如何取得你的帳號資格的？

很多學員會好奇：「AI 怎麼知道我是誰？它會不會偷存我的密碼？」

❓ 學員最擔心的安全疑慮
  • 「AI 怎麼能把東西推到我的 GitHub？」
  • 「我要把 Google 帳號跟密碼告訴 AI 嗎？」
🚨 絕對不用！Antigravity 完全不會、也絕不該知道你的密碼！
🛡️ 官方 OAuth Device Flow 安全規範
  • 一次性 8 碼代碼： 終端機生成隨機驗證碼
  • 官方網頁授權： 在 GitHub 官網手動點擊允許
  • 加密 Token 存本機： 授權後 GitHub 派發憑證到本機
  • 全程零密碼傳遞： 安全等級高達 100%！
4-3 授權實戰

GitHub CLI 8 碼代碼安全配對流程（Device Activation）

只需執行一次！本機產生加密憑證 Token，從此享受終生自動推送

🔍 點擊放大全圖
▲ 圖 4-2：GitHub CLI 8 碼代碼安全配對流程（Device Activation）
步驟 1：AI 觸發授權指令

吩咐「請啟動 GitHub CLI 登入」，終端機顯示一次性 8 碼代碼（如 ABCD-1234）。

步驟 2：瀏覽器開啟官方驗證頁

系統開啟 github.com/login/device，貼入 8 碼按 Continue。

步驟 3：Google 一鍵確認授權

點擊「Authorize github」按鈕，官方立即確認綁定。

步驟 4：本機加密憑證就緒

加密 Token 存於本機，Antigravity 獲得合法建庫與推送權限！

4-4 命名決策

推送時的 Repo 名稱：由 AI 決定還是自己指定？

兩種都可以！完全取決於你在對話框中怎麼對 Antigravity 吩咐

🏷️ 方式 A：由自己指定 Repo 名稱（★強烈推薦）
  • 核心優點： 精確掌控公開網址外觀，絕不意外
  • 口語範例： 「請推送到名為 smartsound-page 的公開 repo...」
  • 產生的公開網址：
    https://<帳號>.github.io/smartsound-page/
🤖 方式 B：讓 Antigravity 依專案自動命名
  • 適用情境： 不想花腦筋想英文名稱的學員
  • 運作原理： AI 自動抓取「目前資料夾名稱」或分析網頁標題
  • 口語範例： 「請幫我取個合適英文名建立 Repo 並推上去...」
