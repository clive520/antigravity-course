3-2 註冊實戰

推薦註冊流程：Continue with Google

極速、零密碼負擔，30 秒快速打通 GitHub 帳號

1️⃣ 步驟 1：前往官網首頁點擊授權

開啟瀏覽器進入 GitHub 官方首頁：
https://github.com/
點選畫面醒目的 「Continue with Google」 或右上角 Sign up，選擇你要綁定的 Google 帳號授權登入。

💡 避免手動輸入長信箱與等待確認信，Google 一鍵授權最順暢！
2️⃣ 步驟 2：設定專屬 Username（使用者名稱）

Google 授權後，系統會要求你輸入一個「全球唯一的使用者名稱（Username）」。

這一步非常關鍵！因為這個英文字串未來會直接變成你的個人首頁與所有網站的永久網址骨幹！

👉 請務必遵循下一頁的命名黃金原則，避免日後後悔！
3-2 網址解密

Username 命名原則與網址結構解密

你的 Username 將直接決定未來所有公開發布網頁的門牌號碼！

🔍 點擊放大全圖

🌐 網址結構對應公式：
https://your-username.github.io/project-name/
✔ 推薦命名原則（Good Practice）：
  • 使用簡短、好記的英文字母與數字（如 alex-tw 或 david-chen）。
  • 使用連字號 - 分隔詞彙，避免難以識別的底線 _。
❌ 避免地雷命名（Bad Practice）：

避免一長串隨機數字亂碼（如 user88392019），否則未來客戶或面試官看到網址會懷疑是釣魚詐騙網站！

3-2 資安警示

使用 Google 帳號註冊的四大注意事項

避開常見新手坑，確保作品與帳號能長期安全保存

1️⃣ 網址不可逆

Username 直接成為永久公開網址。雖然日後可在後台更改，但舊網址外部連結會全部失效，務必一次取好！

2️⃣ 避用學校/公司信箱

.edu 或公司機構信箱在畢業離職後常被收回或封鎖對外授權，將導致無法登入遺失所有作品！請一律用個人 Gmail。

3️⃣ 補設獨立專用密碼

雖然日常網頁用 Google 登入，但第 4 章在終端機執行 gh auth login 時，建議到 Settings 設定一組密碼備用。

4️⃣ 保管 2FA 恢復金鑰

GitHub 強制開啟雙重驗證。如果 Google 帳號或手機遺失，恢復金鑰（Recovery Codes）是救回帳號的唯一鑰匙！

📁 1. Repository（儲存庫 / 簡稱 Repo）

為什麼全世界工程師都離不開 Git？看完這張對照秒懂！

😱 過去的手動存檔悲劇

[Commit 3] 微調按鈕為亮橘色漸層
  • 資料夾永遠只有一份乾淨檔案： 所有歷史紀錄藏在 .git 庫中。
  • 一鍵倒帶： 隨時能回到過去任何一個存檔點，無所畏懼！
3-4 安全防護

必備安全防護：雙重身分驗證（2FA）

GitHub 強制要求！保護你的雲端儲存庫不被駭客盜用

🛡️ 什麼是 2FA（雙重身分驗證）？

即使駭客猜中了你的登入密碼，如果沒有你手機上的「6 位動態即時驗證碼」，也絕對無法登入你的帳號！

目前 GitHub 對全球所有活躍帳號實施強制 2FA 政策，未開啟將會被限制推代碼等關鍵權限。

📱 推薦 Authenticator App：Google Authenticator 或 Microsoft Authenticator。
⚙️ 設定三步驟指引
  • 步驟 1：進入安全選單
    點擊右上角個人頭像 ➔ Settings ➔ Password and authentication。
  • 步驟 2：掃描 QR Code 綁定手機
    點擊「Enable two-factor authentication」，用手機驗證 App 掃描條碼並輸入 6 位碼。
  • 步驟 3：下載備用金鑰（Recovery Codes）
    將系統生成的 16 組備用碼妥善存入保險箱，手機遺失時可用於自救！
