3-2 註冊實戰

推薦註冊流程：Continue with Google

極速、零密碼負擔，30 秒快速打通 GitHub 帳號

1️⃣ 步驟 1：前往官網點擊授權
官方首頁：https://github.com/
  • 點選畫面醒目的 「Continue with Google」 快速登入
  • 免手動輸入長信箱、免等待確認驗證信
💡 Google 一鍵授權登入最順暢，日後隨時可同步！
2️⃣ 步驟 2：設定專屬 Username
  • 輸入一個「全球唯一的英數使用者名稱」
  • 這串英文字會直接變成你的個人首頁與所有網站的永久網址骨幹！
👉 請務必遵循下一頁的命名黃金原則，避免日後外部連結失效！
3-2 網址解密

Username 命名原則與網址結構解密

你的 Username 將直接決定未來所有公開發布網頁的門牌號碼！

🔍 點擊放大全圖
▲ 圖 3-2：GitHub 快速註冊流程與 Username 網址結構解密
🌐 網址結構對應公式：
https://your-username.github.io/project-name/
✔ 推薦命名原則（Good Practice）：
  • 使用簡短、好記的英數字（如 alex-tw 或 david-chen）
  • 使用連字號 - 分隔詞彙，避免難以識別的底線 _
❌ 避免地雷命名（Bad Practice）：

避免隨機數字亂碼（如 user88392019），否則會被客戶或面試官懷疑是釣魚詐騙網址！

3-2 資安警示

使用 Google 帳號註冊的四大注意事項

避開常見新手坑，確保作品與帳號能長期安全保存

1️⃣ 網址不可逆
  • Username 決定網址
  • 日後更改舊連結失效
  • 務必一次取好！
2️⃣ 避用機構信箱
  • .edu 或公司信箱
  • 離職畢業常被收回
  • 請一律用個人 Gmail
3️⃣ 補設專用密碼
  • 日常可用 Google 登入
  • 但終端機執行指令時
  • 建議在 Settings 備妥密碼
4️⃣ 保管 2FA 金鑰
  • GitHub 全球強制 2FA
  • 手機遺失救星
  • 16 組備用碼妥善保存

📁 1. Repository（儲存庫 / Repo）

比喻：雲端專案資料夾。存放這個網站所有程式碼與圖片的專屬保險箱。

💾 2. Commit（提交 / 存檔快照）

比喻：遊戲進度存檔點。記錄「誰在何時修改了什麼」，隨時可坐時光機還原。

🚀 3. Push（推送 / 上傳同步）

比喻：上傳備份至雲端。把你電腦裡做好的存檔點，同步傳到 GitHub 伺服器。

🌐 4. GitHub Pages（全球展示櫥窗）

比喻：免租金的 24H 網路店面。自動把 Repo 變成全世界都能看見的公開網站！

3-3 版本控制

告別「修改噩夢」：Git 版本控制的時光機威力

為什麼全世界工程師都離不開 Git？看完這張對照秒懂！

😱 過去的手動存檔悲劇
index.html
index_修改版.html
index_真的最後版.html
index_打死不改最終版_v3.html
  • 檔案堆滿桌面： 根本分不清哪一個才是正式版本
  • 改壞無法復原： 覆蓋儲存後一旦改壞，心血全部泡湯
⏱️ Git Commit 時光機美學
[Commit 1] 完成 Hero 看板排版
[Commit 2] 增加耳機 4 視角圖片輪播
[Commit 3] 微調按鈕為亮橘色漸層
  • 永遠只有一份乾淨檔案： 歷史紀錄藏在 .git 中
  • 一鍵倒帶： 隨時能回到過去任何存檔點，無所畏懼！
3-4 安全防護

必備安全防護：雙重身分驗證（2FA）

GitHub 全球強制要求！保護你的雲端儲存庫不被駭客盜用

🛡️ 什麼是 2FA（雙重身分驗證）？
  • 密碼遭竊也不怕： 必須搭配手機「6 位動態即時驗證碼」才能登入
  • GitHub 全球強制： 活躍帳號皆須開啟，保障開發者資安
📱 推薦驗證器：Google Authenticator 或 Microsoft Authenticator。
⚙️ 設定三步驟指引
  • 步驟 1：進入安全設定
    點擊個人頭像 ➔ Settings ➔ Password and authentication
  • 步驟 2：手機 App 掃描條碼
    使用驗證 App 掃描 QR Code 並輸入 6 位碼確認綁定
  • 步驟 3：下載備用金鑰（Recovery Codes）
    將 16 組備用碼妥善儲存，手機遺失時可用於自救！
