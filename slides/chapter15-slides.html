資深心法 · SECURITY

自癒兩大防護網：三大保險讓人類放心離席

如何防止 AI 半夜搞壞系統或無窮耗費 Token 燒錢？

🛡️ 1. Git 分支沙盒隔離

在執行前切出獨立工作分支（如 auto-refactor），所有修改都在沙盒中進行，主分支絲毫不受影響，隨時可一鍵還原。

🔄 2. 快照回溯 (Rollback)

每完成一個 Milestone 自動打 Commit 快照；一旦自檢未過，AI 會自動 git reset 恢復乾淨狀態，絕不把錯誤代碼硬推上線。

🛑 3. 最大步數預算 (Budget)

設定 max_steps 與超時心跳機制；若重試 5 次仍無法攻克，AI 會自動安全中斷並生成診斷日誌，絕不無窮空轉燒 Token！
