第 14 章 · 跨界工具生態協議

MCP 協議跨界實戰：連接 Obsidian 與本機工具，打造個人專屬「第二大腦」知識提煉系統

打破 AI 的孤島極限！傳統的聊天機器人就像關在玻璃房裡的天才，根本碰不到你電腦裡的真實筆記與檔案。本章解鎖全球次世代標準——MCP（Model Context Protocol，模型上下文協議）。如同為 AI 裝上萬能 USB 擴充槽，讓 AntiGravity 直連本機 Obsidian 筆記庫，自動提煉每日工作心得、補齊 [[雙向反向連結]]，並親眼見證你的個人知識星系圖譜發光聯網！

14-1 觀念破冰：打破孤島！什麼是 MCP 模型上下文協議？

很多學員每天都在用 AI，但也深刻體會過這種無奈：

❌ 玻璃房裡的 AI 天才

AI 很聰明，但它看不到你電腦裡累積多年的工作筆記、會議記錄與靈感草稿。每次都要手動複製貼上，麻煩又中斷思緒。

❌ 散亂的「數位垃圾場」

隨手記在 Obsidian 或記事本裡的東西雜亂無章，過兩週就忘光，從來沒有時間好好整理，更不會主動形成知識關聯。

❌ 手動打雙向連結太痛苦

聽說 Obsidian 的 [[雙向連結]] 很強，但每個詞都要手動打中括號，維護成本太高，最後半途而廢。

💡
白話解密：MCP 就是「AI 時代的萬能 USB-C 擴充塢」！
Model Context Protocol（MCP） 是一套開放標準協議。只要插上這條線，AI 就能長出雙手雙腳，安全地讀取你本機的 Obsidian 筆記庫、本地硬碟檔案與資料庫，全程資料不出門，100% 本機隱私保證！

14-2 工具插槽就緒：Obsidian 安裝、雲端整合與基本使用心法

在讓 AntiGravity 幫你打理筆記之前，我們先花 3 分鐘把這座專屬的「第二大腦基地」搭建起來。Obsidian 是目前全球公認最強大的個人知識管理軟體，核心優勢在於「純文字 Markdown 儲存、零資料綁定、永久可用」。

STEP 1

Obsidian 下載安裝與「Google 雲端硬碟」跨裝置整合心法

  1. 下載軟體（完全免費）：前往官網 obsidian.md 下載對應版本（Windows / Mac / Linux），安裝過程免註冊帳號，開箱即用。
  2. 關鍵心法：筆記庫（Vault）首選「Google 雲端硬碟」：
    💡 為什麼強烈推薦選 Google Drive？
    • 跨機器無縫同步：只要安裝「Google 雲端硬碟電腦版」，公司桌機與家裡筆電就能自動雙向同步筆記，完全不需額外購買昂貴的雲端同步服務！
    • 純文字極致省空間：數千篇 Markdown 筆記通常只有幾十 MB，絲毫不佔硬碟。
    • 雙重備份防呆：Google Drive 內建歷史版本回溯，加上 Obsidian 內建的「檔案還原（File Recovery）」，筆記永遠不怕手殘誤刪！
  3. 建立筆記庫：打開 Obsidian 點擊「建立新筆記庫（Create new vault）」，命名為 MyBrain，路徑直接選擇你的 Google 雲端硬碟資料夾（例如 G:\我的雲端硬碟\MyBrain）。
STEP 2

Obsidian 基本使用方式與高效率「資料收集心法」

📝 1. 純文字 Markdown 語法

使用 # 大標題、## 中標題、- 條列清單、**粗體**，排版清爽優雅，在任何軟體打開都是通用純文字。

🔗 2. 靈魂魔法：[[雙向連結]]

只要打出兩個中括號 [[筆記名稱]]，Obsidian 就會自動建立超連結！點擊就能跨頁面跳轉，筆記之間互相串聯成網。

🌌 3. 關係星系圖 (Graph View)

按下快捷鍵 Ctrl + G（Mac 為 Cmd + G），一鍵展開壯觀的 3D 知識網絡圖，親眼看著你的思想神經元發光生長。

📥 建立你的「00_Inbox 靈感收納箱」資料流：

平時看到好文章或有突發靈感，不要給自己「該分類到哪」的心理壓力！統一建立一個 00_Inbox/ 資料夾，隨手記成便條草稿丟進去。 人類只管負責收集，而最花時間的「分類整理、打標籤、建立雙向連結」，接下來全部交給 AntiGravity 透過 MCP 來自動完成！

當本機 Obsidian 筆記庫準備就緒後，AntiGravity 就能透過 MCP 協議直接「插上擴充插槽」，擁有以下四大特工級武器：

🏆 圖 14-1：AntiGravity MCP 跨界直連生態管線
核心大腦 ➔ MCP 通用協議 ➔ 直連本機 Obsidian 筆記庫 ➔ 自動建立雙向 WikiLinks ➔ 點亮動態知識星系圖譜。

🧩 MCP 賦予 AI 的 4 大超能力：

  1. read_note：直讀筆記。AI 能直接調閱你電腦中任何一份 .md 筆記，不必人工複製貼上。
  2. patch_note：局部微修。只替換筆記中的某個段落，保留你原有的排版與格式，絕不覆寫整份筆記。
  3. write_note：建立新篇。自動在筆記庫建立全新專題、總目錄（MOC）或每日日記（Daily Notes）。
  4. search_notes：全庫檢索。毫秒級搜尋上百篇筆記中的關鍵術語，找出潛在關聯性。

14-3 核心動手做：打造耳機電商專案的「第二大腦」

在前面第 1 ~ 13 章中，我們累積了許多零散的專案筆記（耳機規格、競品報告、定價策略、自癒測試）。現在我們要讓 AI 自動替我們將它們串聯成一座「互相連結的知識神經網絡」：

STEP 1

準備工作：本機 Obsidian 筆記庫（Vault）結構

你的筆記庫裡有幾篇隨手記錄的草稿檔案：耳機專案.md、降噪技術.md、定價策略.md、自癒測試.md。

STEP 2

下達作戰指令：一鍵啟動知識提煉與雙向連結

黃金指揮官 Prompt：Obsidian 第二大腦提煉指令 
請透過 MCP 協議讀取我的 Obsidian 筆記庫中關於『AeroPulse Pro 耳機專案』的相關筆記：

1. 智能概念萃取：分析各篇筆記內文，自動辨識核心術語（如「降噪技術」、「定價策略」、「自癒測試」、「客群畫像」）。
2. 自動雙向連結：在每篇筆記的適當語句中，自動注入 [[雙向反向連結]] 語法，建立筆記之間的超連結紐帶。
3. 知識地圖產出：在筆記庫根目錄建立一份全新總目錄『Course_MOC.md（Map of Content）』，以結構化大綱列出整個專案的知識脈絡與各頁面導航連結。
4. 保持乾淨排版：只使用局部更新（patch），絕不破壞我原有記錄的文字與筆記結構！
STEP 3

成果驗收：打開 Graph View 親見知識星系發光

AI 執行完畢後，切換回 Obsidian 軟體，按下快捷鍵 Ctrl + G 打開關係圖譜（Graph View），原本各自孤立的小圓點瞬間長出了無數條連結絲線，發光連成一體！

14-4 初學者實戰寶庫：三大生活化 MCP 應用實戰（情境、暗坑與提示詞）

MCP 不只可以用在專案開發，更能融入你的日常生活與工作流中！以下提供初學者最實用的三大生活實例：

📝 案例一：【日常閱讀】零散隨筆「自動雙向連結與標籤整理器」

適用：讀書心得 / 靈感隨筆

生活痛點：平常看 YouTube 影片、商業文章隨手記了幾段話在 Obsidian，內容東拼西湊、排版凌亂。想把這些筆記整理成有系統的心得，手動分類與打連結要花上一小時。

黃金指揮官 Prompt：靈感隨筆自動整理 
請透過 MCP 讀取我 Obsidian 筆記庫中『每日靈感/』資料夾下的最新 3 篇筆記：

1. 幫我梳理這三篇筆記的核心洞察，去除流水帳贅詞。
2. 自動為內文中的關鍵術語加上 [[雙向連結]]（例如概念名稱、名詞定義）。
3. 在文章開頭補上標準 Frontmatter 標籤（如 tags: [AI學習, 商業靈感]）。
4. 直接更新回對應的本機檔案中，保持原有格式乾淨整齊！
🎁 驗收成果：不用手動編輯，打開 Obsidian 發現三篇筆記已經自動補齊 YAML 標籤與發光的雙向連結，隨手記的零碎草稿立刻變成正規知識庫！

🗂️ 案例二：【個人秘書】本機混亂桌面「一鍵智慧歸檔與 Daily Note 備忘錄」

適用：檔案整理 / 每日日記

生活痛點：電腦桌面堆滿了「未命名的截圖.png」、「會議記錄草稿.txt」、「發票明細.pdf」，每次找檔案像大海撈針。知道該整理，但一想到要把檔案一個個建資料夾放進去就頭痛拖延。

黃金指揮官 Prompt：桌面檔案秘書與日記歸檔 
請啟動桌面秘書特工，透過本機檔案工具檢查我的『桌面暫存區/』：

1. 自動辨識每個檔案的主題，將它們分類移至合適的歸檔資料夾（例如：/發票收據、/會議記錄、/教學截圖）。
2. 透過 MCP 在我的 Obsidian 建立今天的 Daily Note『2026-10-26.md』。
3. 在這份筆記中，列出剛才整理的檔案清單與一目了然的一句話摘要，並標記明天需要追蹤的代辦事項！
🎁 驗收成果：桌面瞬間變乾淨，打開今天的 Obsidian 日記，整整齊齊記錄著今天歸檔的所有內容與明日待辦，宛如請了一位貼身秘書！

🗺️ 案例三：【視覺理解】複雜架構筆記「自動繪製 Mermaid 關係流程圖」

適用：架構分析 / 流程圖解

14-5 旗艦生活拓展：利用 MCP 操控 Google 全家桶與網頁自動化（人機協同實戰）

學會了讓 AI 整理本地筆記後，很多學員會問：「MCP 還能幫我做什麼更貼近日常生活的神奇任務？」答案是：掌控你每天都在用的 Google 雲端生態與真實網頁操作！

過去你需要在十幾個瀏覽器分頁切來切去：複製客戶信件、貼到 Excel 計算報價、開日曆查檔期、開 Word 起草合約，或者在各大機票網站被複雜的航班資訊搞得頭昏眼花。現在，透過 MCP 協議，AntiGravity 可以像一位「長了雙眼與雙手的全能秘書」，把這一切自動串接起來！

🌐 旗艦應用一：Google 全家桶 MCP 實戰 — 一人工作室的「全自動 VIP 商務秘書」

Gmail / 日曆 / 試算表 / 文件 / 簡報 / 雲端硬碟

生活 / 商業痛點：身為自由接案者、個人工作室老闆或專案經理，每天收到潛在客戶的合作信件後，需要手動經歷整整 6 道繁瑣工序：登入 Gmail 閱讀需求 ➔ 打開 Google Sheets 登錄商機並試算報價 ➔ 查看 Google Calendar 尋找會議空檔 ➔ 複製 Google Docs 範本起草合作協議 ➔ 製作 Google Slides 提案簡報初稿 ➔ 最後再寫信回覆客戶。全套流程往往耗去 1~2 個小時。

🧩 Google Workspace MCP 工具插槽協同地圖：
📧 Gmail MCP：抓取未讀合作郵件、提煉需求重點、起草回覆信草稿
📊 Google Sheets MCP：自動新增潛在客戶行、輸入工時並自動計算總報價
📅 Calendar MCP：比對行事曆既有排程、找出下週 3 個 30 分鐘諮詢空檔
📝 Google Docs MCP：呼叫制式合約模板、動態填入客戶名稱與項目規範
📽️ Google Slides MCP：根據專案架構自動生成 5 頁極簡專業 Pitch 簡報
📁 Google Drive MCP：在指定專案資料夾自動歸檔並設定客戶檢閱分享連結
黃金指揮官 Prompt：Google 全家桶全自動接案秘書 
請啟動 Google Workspace 綜合秘書流程，透過 MCP 協議依序執行以下任務：

1.【讀取郵件 (Gmail)】：
  搜尋今天主旨包含「合作洽詢」或「專案報價」的最新 1 封未讀郵件，萃取：發信人、公司名稱、需求摘要、預算範圍。

2.【登錄商機與試算 (Google Sheets)】：
  打開我 Google 雲端硬碟中的「2026_業務商機追蹤表.xlsx」：
  - 在「潛在客戶」工作表最下方追加一筆記錄（記錄發信人、公司名稱、日期與需求項目）。
  - 根據需求項目，自動填入對應工時與費率公式，計算出建議報價金額。

3.【排定諮詢時段 (Google Calendar)】：
  檢查我下週一至週三的行事曆，找出 3 個沒有任何會議衝突的 30 分鐘下午時段（例如 14:00~14:30、15:30~16:00）。

4.【起草意向書與簡報 (Google Docs & Slides & Drive)】：
  - 在 Google Drive 的「專案提案區/」下，以 Docs 建立一份「合作意向備忘錄_草案.docx」，填入剛才試算的報價與工作項目。
  - 以 Slides 建立 5 頁簡報草稿：封面、客戶痛點、解決方案、時程規劃、報價方案。
  - 將這兩個檔案設定為「擁有連結者可檢閱」，並取得分享網址。

5.【起草回信草稿 (Gmail)】：
  在 Gmail 中針對該信件起草一封親切有禮的繁體中文回信草稿（絕對不要直接寄出！）：
  - 感謝對方的合作意向並條列簡述我們能提供的解決方案。
  - 附上下週可進行線上會議的 3 個建議時段供對方選擇。
  - 附上 Google Docs 意向書與 Google Slides 簡報的預覽連結。
  - 提示對方：「回覆確定時段後，我將為您發送 Google Meet 會議邀請。」

完成後，請在對話框彙報執行進度，讓我直接前往 Gmail 檢查草稿！
🛡️ 關鍵安全防呆心法（Draft First 原則）：
涉及外部客戶溝通時，一律要求 AI「起草為草稿（Draft）」，嚴禁直接自動點擊寄出！ 人類花 30 秒在 Gmail 檢查確認文字語氣與附件連結無誤後，親手按下一鍵發送，既節省 90% 的重複工作，又保證 100% 的商業信譽安全！

✈️ 旗艦應用二：真實網頁自動化操控 — 東京賞櫻機票比價、自動填單與信用卡安全接棒（HITL）

Browser MCP + Human-in-the-Loop
