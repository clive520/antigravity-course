第 9 章 · 現代雲端軍火庫

現代雲端邊緣平台：認識 Cloudflare 全家桶（網頁、資料庫、檔案庫與免費額度全解）

在現代軟體工程界，Cloudflare 已不僅僅是一家防護網路攻擊的公司，它已經進化為全球開發者公認的「最強 Serverless 雲端軍火庫」！本章將全面解構 Cloudflare 的五大核心能力：網頁託管 (Pages)、邊緣運算 (Workers)、三大分散式資料庫 (D1 / KV / Vectorize)、零流量費檔案儲存 (R2) 與企業門禁 (Zero Trust)，並附上最完整的永久免費額度指南，為第 10 章的企業級 AI 知識庫做好最扎實的技術準備！

9-1 概念進化：從 GitHub 跨入 Cloudflare 全球 330+ 邊緣節點

在第 3、4 章中，我們學會使用 GitHub Pages 發布網站。GitHub Pages 很好，但它是以美國西岸為主的單一靜態伺服器，亞洲訪客開啟時延遲常在 150～300 毫秒（ms）。

而 Cloudflare 擁有全球超過 330 個城市的 Anycast 邊緣網路（包含台北、高雄與香港）。當台灣的使用者點開你的網址時，請求是由離他最近的本地資料中心在 10～30 毫秒內 瞬間回應！

🌐 圖 9-1：傳統單一託管 vs. Cloudflare 全球邊緣 Anycast CDN 架構進化
資料直接駐留在邊緣，帶來極致的載入速度，並自帶免費 SSL 萬用憑證與頂級 DDoS 流量防護。

9-2 網頁與運算雙核心：Cloudflare Pages 託管與 Workers 邊緣運算

1. Cloudflare Pages（現代前端網站託管）

專門用來放 HTML、CSS、JavaScript 靜態網站或 React/Vue 前端專案：

  • 一鍵 Git 整合：授權 GitHub 儲存庫，每次 git push 後 10 秒內全球自動編譯上線。
  • 分支獨立預覽（Preview Deployments）：開新分支時，Cloudflare 自動為該分支派發獨立測試網址，主管與客戶驗收不干擾正式線上網站。
  • 自訂網域免煩惱：免費綁定專屬品牌網域名稱，永久自動配置免費 SSL 安全鎖頭。
  • 🎁 免費額度：⭐ 出站流量永遠完全無限制（Unlimited Bandwidth）！每月提供 500 次自動建置（Builds）。

2. Cloudflare Workers（無伺服器邊緣後端）

不用租用虛擬主機，直接在全球 330+ 節點上執行輕量後端代碼：

  • 毫秒級冷啟動（< 5ms）：採用 Google V8 隔離區技術，速度是傳統 AWS Lambda 的 100 倍。
  • 金鑰安全保管（Secrets）：後端支援環境變數加密，可安全存放 Google API Key 或資料庫密鑰，前端瀏覽器完全看不到！
  • 全端一體化（Pages Functions）：只要在專案新增 functions/ 目錄，就能讓靜態網站秒變具備 API 後端運算能力的全端系統。
  • 🎁 免費額度：⭐ 每天 100,000 次免費請求（10 萬次/天），每次請求享有 10ms CPU 執行時間（等待網路/資料庫的 I/O 時間不計入）。

🤠 什麼是 Wrangler？Cloudflare 官方開發者核心司令官

Wrangler 是 Cloudflare 官方專為開發者打造的核心命令列工具（CLI，Command-Line Interface）。
如果 Cloudflare 網頁後台（Dashboard）是「汽車儀表板上的觸控螢幕」，那麼 Wrangler 就是「工程師手上的專業遙控手把與自動駕駛程式碼」！就像我們在第四章使用 gh 控制 GitHub 一樣，在 Cloudflare 世界裡，控制所有邊緣運算與雲端資料庫的司令官就是 wrangler。

💡 有趣的命名由來："Wrangler" 在英文中原意是指「牛仔、馴馬師」（專門馴服並管理狂奔的野馬群）。Cloudflare 用這個名字象徵：「用這一套工具，幫你輕鬆馴服並駕馭分散在全球 330 多座城市的邊緣伺服器與微服務！」
🛠️ Wrangler 的 6 大主要超能力：
1. 🚀 一鍵發布與全球部署
wrangler pages deploy 或 wrangler deploy 秒級同步分發到全球 330+ 節點。
2. 💻 本地極速模擬環境
wrangler dev 在本機模擬完整邊緣環境，支援熱重載（Hot Reload）秒看成果。
3. 🗄️ 邊緣資料庫全生命週期
建立 D1 關聯資料庫、執行 SQL 腳本建表、管理 KV 快取與 Vectorize 向量庫。
4. 📦 R2 零流量費檔案儲存
建立儲存桶（Bucket）、直接上傳與下載手冊 PDF 與圖片等靜態資產。
5. 🔒 安全加密環境變數
wrangler secret put 將 Gemini API Key 加密上傳至雲端，代碼絕不洩漏金鑰。
6. 📡 即時線上日誌監聽
wrangler tail 在終端機即時串流使用者造訪日誌與錯誤代碼，線上抓 Bug 神器！
🤖 為什麼讓 AntiGravity 掌握 Wrangler 如此重要？

過去搭建雲端應用，需要在後台手動點擊建 Pages、建 Workers、建 D1、填 Secrets...繁瑣容易出錯。現在有了 Wrangler，你只要動口吩咐：「AntiGravity，請用 wrangler 幫我建立一個名為 handbook-db 的 D1 資料庫，並把寫好的後端部署上去！」——AntiGravity 就能自動在命令列代勞秒級完成！

🔑 授權方式：如何讓 Antigravity 取得 Wrangler 控制權？

方式 A：瀏覽器互動登入（適合個人開發）

在終端機輸入一行指令： 

npx wrangler login

系統會自動開啟預設瀏覽器跳出 Cloudflare 授權頁面，點選「Allow（同意授權）」即大功告成！憑證會自動儲存在電腦本機中。

方式 B：API Token 權杖（推薦！AI 與自動化最穩）

免跳出瀏覽器、不卡終端機的專業做法：

  1. 登入 Cloudflare ➔ 右上角「我的設定檔」➔「API 權杖」。
  2. 點擊「建立權杖」，選用「Edit Cloudflare Workers」範本。
  3. 在專案根目錄 .env 放入：
    CLOUDFLARE_API_TOKEN=你的權杖
💬 授權後你可以對 Antigravity 說的指令：
「Antigravity，請使用 wrangler 幫我把目前的網頁目錄部署到 Cloudflare Pages，專案名稱叫做 my-handbook-web！」
🤔 架構思考：方式 A 與方式 B 除了過程不同，控制的內容是一樣的嗎？

簡短答案是：「日常操作看起來很像，但就本質而言，控制的權限範圍與安全邊界完全不同！」

方式 A（wrangler login）➔「萬能金鑰」

點擊同意後，等於將你本人的整個人格身分（Account Admin）授權給本機。它擁有你 Cloudflare 帳號的全部權限（包含修改全站 DNS、防火牆與帳單），方便但屬於「權限全開（Overprivileged）」。

方式 B（API Token）➔「特定門禁卡（最小權限原則）」

控制內容嚴格受限於你在後台勾選的權限。勾選 Workers 權限的 Token 就絕對動不了你的頂級網域 DNS 或帳單，即便 Token 外洩也無法影響整個帳號。

比較維度 方式 A：瀏覽器登入 (wrangler login) 方式 B：API Token 權杖 (.env)
權限範圍 無限制（全帳號所有權限） 精確受控（最小權限原則）
生效範圍 全電腦所有專案共用（Global） 單一專案獨立隔離（Project-Isolated）
有效期限 長期有效（自動更新 Refresh Token） 可自訂到期日（過期自動失效）
來源 IP 限制 無法限制來源 IP 可限制只有特定公司/家中 IP 能調用
適用情境 個人開發快速練習 讓 AI 代理自動化、正式企業上線首選

9-4 檔案資料庫 R2：完全免出站頻寬費（Zero Egress Fees）的 S3 相容儲存

在雲端儲存領域，AWS S3 是最知名的物件儲存服務，但它有一項令所有企業聞風喪膽的收費陷阱——「下載流量費（Data Egress Fees）」！當你的使用者頻繁下載 PDF 或圖片時，每 GB 都要被抽取高額頻寬費。

🔥 Cloudflare R2 的革命性承諾：

Cloudflare R2 完全相容 Amazon S3 的 API，用來存放**公司規章 PDF、圖片、備份檔或大容量文件**，並做出了顛覆業界的承諾：

  • ⭐ 出站下載流量費永遠為 0 元（$0 Egress Fees）：無論檔案被下載幾百萬次，頻寬費用永遠是 0 元！
  • 🎁 免費儲存容量：**每個月 10 GB 永久免費**！
  • 🎁 免費操作次數：每月 100 萬次上傳/寫入（Class A），以及每月 1,000 萬次讀取/下載（Class B）！

9-5 企業安全門禁：Cloudflare Zero Trust Access 前 50 人完全免費

很多開發者自己寫網站，最怕把內部管理系統或手冊放到公開網路上被外人看光。傳統做法必須自己寫使用者帳號表、登入畫面、加密密碼與 Session 機制，既費時又容易有資安漏洞。

🛡️ 免寫一行登入程式！零信任身分防護牆：

Cloudflare 提供了名為 Zero Trust (Access) 的頂級安全功能：

  1. 只要在後台勾選設定，就能在網頁前罩上一道安全門禁。
  2. 限制企業郵件網域：設定只有 @yourcompany.com 的同仁輸入 Email 收到一次性 6 碼驗證 PIN 碼，或透過 Google Workspace 登入才能進入。
  3. 無授權的外部陌生訪客會直接被邊緣防火牆阻絕（403 Forbidden），完全摸不到內部網頁！
  4. 🎁 免費額度：⭐ 前 50 位使用者（Seats）永久完全免費，極度適合中小企業、新創團隊與內部專案！
