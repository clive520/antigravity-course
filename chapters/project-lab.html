多人即時在線物理化學實驗室：零資料庫架構、Antigravity 提示詞引導與可擴充外掛體系

擺脫單機版點擊！本單元帶你建造一個具備「多人同屏協同、即時幽靈游標（Ghost Cursors）、酸鹼滴定突躍與天體引力模擬」的現代化線上實驗室。最關鍵的是：全程完全不需要資料庫、零伺服器成本，且具備外掛式架構，未來只要新增一個檔案就能無限擴充新實驗室！

🧪 立即啟動線上實驗室 (可雙開分頁測試) ↗

1. 專案目標：打破單機孤島，打造同屏協同的數位科學樂園

很多學員在求學或教學過程中都接觸過線上模擬實驗（例如知名的 PhET）。但傳統線上實驗室存在一個最大的遺憾：

❌ 孤獨的單機操作

學生只能各自對著螢幕點擊，缺乏實體實驗室中「一人拿試管、一人讀刻度、大家共同討論」的團隊協同感。

❌ 封閉僵化的架構

很多模擬程式把物理公式、按鈕 UI 與畫面全寫在同一個檔案裡。想新增一個新實驗，必須重寫整套系統。

❌ 繁重的後端與維護負擔

一提到多人連線，很多人以為要租昂貴的伺服器、架設 WebSocket 伺服器、開 SQL 資料庫，維護門檻極高。

💡
OmniLab 的三大破局目標：
1. 多人即時同屏（Real-time Co-Presence）：在同一房間內，彼此能看見彩色的「幽靈游標」、共同控制滴定旋塞、共同投放星體。
2. 外掛註冊機制（LabRegistry）：所有實驗皆為獨立模組，未來只需新增單一檔案即可自動掛載！
3. 零後端、零資料庫部署：以瀏覽器原生技術實現，直接發布在免費 GitHub Pages 上即可全球暢玩！

2. 軟體環境建置：純前端、零依賴、零資料庫的高抗壓架構

在設計複雜網頁時，最怕陷入「安裝了幾百個 npm 套件，結果換台電腦就跑不起來」的窘境。本專案採用最優雅的現代瀏覽器原生技術棧：

🧩 核心軟體環境與技術組成：

  1. 原生 ES Module（import / export）：無需 Webpack 或 Vite 打包工具，不用安裝 Node.js，開箱直接在瀏覽器運行。
  2. HTML5 Canvas 2D 高速物理引擎：利用 requestAnimationFrame 驅動 60 FPS 物理數值積分與粒子流體特效，支援 Retina 螢幕高解析度自適應。
  3. 雙模式即時傳輸層（RealtimeSync）：
    • 本地零門檻：使用瀏覽器原生 BroadcastChannel API，同一台電腦開兩個分頁即時互通，延遲小於 1 毫秒！
    • 雲端跨網：預留第 10 章學過的 Supabase Realtime Broadcast 接口，填入 Key 即可跨縣市連線。

🤔 為什麼「即時互動」完全不需要資料庫？

每秒 60 次的滑鼠移動或水滴落下，屬於「短暫狀態電報（In-Memory Telemetry）」。
如果把每一毫秒的座標都寫進硬碟資料庫，不但會因為磁碟 I/O 造成延遲卡頓，還會白白浪費幾千萬筆無意義的硬碟空間。因此，我們讓數據直接在記憶體中像無線電波一樣廣播，接收端畫出畫面後立即釋放，既省流量又做到極致順暢！

3. 多人即時同步核心：運作秘密大解密

很多學員好奇：「為什麼兩台電腦之間的游標能像面對面一樣同步飛舞？」其核心運作包含三大步驟：

📐

1. 座標歸一化 (0~1)

不同學員的螢幕大小不同（桌機 vs 筆電）。我們將滑鼠點位轉換為比例 x = mouseX / width，確保在任何解析度下位置分毫不差。

⚡

2. 極小操作電報

絕不傳輸畫面錄影！只廣播動作指引（例如 { action: "DROP", volume: 0.05 }，僅 40 Bytes），各端電腦各自計算化學反應。

〰️

3. 平滑插值 (LERP)

遠端游標透過數學線性插值計算：x += (targetX - x) * 0.25，即使網路稍有波動，夥伴的游標依然絲滑柔順、絕不閃爍跳動。

4. 如何下提示詞：引導 Antigravity 打造複雜架構的指揮術

在面對「60 FPS 動態渲染 + 即時同步 + 多模組外掛」這樣龐大的專案時，如果只下單純的一句話「幫我寫一個物理化學實驗室」，AI 很容易生成出塞在單一檔案裡的巨大代碼。身為指揮官，我們要引導 Antigravity 依循「四階段漸進式提示詞」完成建造：

第一階段 Prompt：規劃外掛註冊架構與目錄規範

系統底座

指令目的：要求 AI 採用模組化設計，先建立「實驗室註冊中心（LabRegistry）」與「核心渲染循環（LabEngine）」。

引導指令：架構與外掛中心 
我想製作一個純前端的「多人即時在線物理化學實驗室（OmniLab）」，請幫我規劃可無限擴充的外掛式架構：
1. 採用原生 ES Module，不要使用任何打包工具。
2. 設計一個「LabRegistry」模組註冊表，所有實驗室都必須符合統一介面（id, name, init, update, render, onRemoteAction, destroy）。
3. 建立「LabEngine.js」處理 60 FPS 物理循環、高清 Canvas 適應，以及在上層繪製遠端夥伴的幽靈游標。
4. 請先建立核心目錄結構與基礎檔案骨架。

第二階段 Prompt：實現零伺服器多人同步層 (RealtimeSync)

即時通訊

指令目的：引導 AI 使用原生 `BroadcastChannel` 實現本地雙分頁連線，並定義游標與動作廣播規格。

引導指令：多人同步層實作 
請為我們的實驗室撰寫「RealtimeSync.js」多人即時同步類別：
1. 使用瀏覽器原生 BroadcastChannel 建立房間通訊，使用者可隨機分配科學家暱稱（如愛因斯坦、居禮夫人）與發光游標顏色。
2. 提供 broadcastCursor(normX, normY) 方法，節流 33ms 發送游標比例座標。
3. 提供 broadcastAction(actionType, payload) 方法，廣播實驗操作。
4. 定期維護 Presence 心跳，動態回傳當前在線人數與成員列表。

第三階段 Prompt：開發首發雙實驗室（化學滴定與萬有引力）

科學演算法

指令目的：明確告知 AI 化學平衡式、指示劑變色規則，以及牛頓萬有引力與克卜勒軌道預覽演算法。

引導指令：雙實驗室演算法 
請依據 LabRegistry 規範實現兩個外掛實驗室：
1.『exp1-titration.js』酸鹼滴定實驗：
  • 包含滴定管、旋塞、反應燒杯與磁力攪拌器漩渦動畫。
  • 依據已加 NaOH 毫升數真實計算 pH 值；支援酚酞（無色突變粉紅）與廣用指示劑。
  • 右側即時繪製 pH 滴定突躍 S 型曲線圖表；旋塞動作透過 sync.broadcastAction 同步給夥伴。
2.『exp2-gravity.js』萬有引力天體沙盒：
  • 牛頓萬有引力多體運動；支援投放行星、恆星與黑洞。
  • 滑鼠拖曳時，即時虛線計算並預覽未來 120 步的克卜勒公轉軌跡，且廣播給房間內其他夥伴看見！

5. 成果展示與雙分頁實測驗收

跟著上述步驟完成後，我們獲得了一套功能完整的現代化虛擬實驗室：

🧪 🌌 👥

OmniLab 線上實驗室實機運行已就緒！

點擊下方按鈕啟動實驗室。進入後，點擊右上角「⚡ 雙分頁同步測試」按鈕，瀏覽器將自動在右半邊螢幕彈出另一個視窗！親自體驗移動左邊滑鼠，右邊螢幕的幽靈游標跟著移動；左邊滴定一滴試劑，右邊燒杯液體同步變色！

6. 10 分鐘無限擴充新實驗室：複製外掛模板即可啟用！

因為我們在一開始就設計了 `LabRegistry` 外掛機制，未來無論你想做什麼新實驗（例如「串並聯電路實驗室」或「光學透鏡折射實驗室」），只要照著以下 3 步即可無痛擴充：

🛠️ 擴充新實驗室三步驟：

  1. 複製模板檔案：打開專案中的 labs/js/experiments/exp-template.js，另存為你的新檔案（例如 exp3-circuit.js）。
  2. 填入生命週期代碼：在 update(dt) 寫物理運算、在 render(ctx) 畫電路儀表、在 onRemoteAction 同步開關狀態。
  3. 在 index.html 引入：只需在 labs/index.html 開頭加上一行 import "./js/experiments/exp3-circuit.js";，頂部選單便會自動長出按鈕，開箱即用！
