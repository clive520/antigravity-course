專案工坊 · 高階互動應用

多人即時在線物理化學實驗室：零資料庫架構、跨帳號雲端 WSS、Antigravity 提示詞引導與可擴充外掛體系

擺脫單機孤島！本單元帶你建造一個具備「多人跨帳號同屏協同、即時幽靈游標（Ghost Cursors）、酸鹼滴定突躍與天體萬有引力模擬」的現代化線上實驗室。最關鍵的是：完全零伺服器維護成本、免自建資料庫、免申請 API Key，且具備高可擴充外掛架構，只要新增單一檔案就能無限擴充新實驗！

🧪 立即啟動線上實驗室 (支援跨帳號/跨裝置) ↗

1. 專案目標：打破單機孤島，打造同屏協同的數位科學樂園

很多學員在求學或教學過程中都接觸過線上模擬實驗（例如知名的 PhET）。但傳統線上實驗室存在一個最大的遺憾：

❌ 孤獨的單機操作

學生只能各自對著螢幕點擊，缺乏實體實驗室中「一人拿試管、一人讀刻度、大家共同討論」的團隊協同感。

❌ 封閉僵化的架構

很多模擬程式把物理公式、按鈕 UI 與畫面全寫在同一個檔案裡。想新增一個新實驗，必須重寫整套系統。

❌ 繁重的後端與維護負擔

一提到多人即時連線，很多開發者直覺以為一定要租伺服器、寫 Node.js Socket、開 SQL 資料庫，維護門檻極高。

💡
OmniLab 的三大破局目標：
1. 多人即時同屏（Real-time Co-Presence）：在同一房間內，不同帳號、不同電腦的夥伴能看見彼此彩色的「幽靈游標」、共同控制滴定旋塞、共同投放星體。
2. 外掛註冊機制（LabRegistry）：所有實驗皆為獨立模組，未來只需新增單一檔案即可自動掛載！
3. 零後端、零資料庫部署：以純前端現代技術實現，直接發布在免費 GitHub Pages 上即可全球暢玩！

2. 軟體環境建置：純前端、零依賴、零資料庫的高抗壓架構

在設計高互動網頁時，最怕陷入「安裝了幾百個 npm 套件，換台電腦就跑不起來」的維護惡夢。本專案採用最優雅的現代瀏覽器原生技術棧：

🧩 核心軟體環境與技術組成：

  1. 原生 ES Module（import / export）：無需 Webpack 或 Vite 打包工具，不用安裝 Node.js，開箱直接在瀏覽器運行。
  2. HTML5 Canvas 2D 高速物理引擎：利用 requestAnimationFrame 驅動 60 FPS 物理數值積分與粒子流體特效，支援 Retina 螢幕高解析度自適應。
  3. 雙層即時傳輸體系（RealtimeSync）：
    • 雲端跨網主通道：採用開源免金鑰 Secure WebSocket（MQTT Broker: wss://broker.emqx.io:8084/mqtt），支援跨帳號、跨瀏覽器、跨手機與筆電多人同頻！
    • 本地同源保底通道：整合瀏覽器原生 BroadcastChannel API，即使無網路環境也能雙分頁超速互通（延遲 < 1ms）。

🤔 為什麼「即時互動」完全不需要資料庫？

每秒 60 次的滑鼠移動或水滴落下，屬於「短暫狀態電報（In-Memory Telemetry）」。
如果把每一毫秒的座標都寫進硬碟資料庫，不但會因為磁碟 I/O 造成延遲卡頓，還會白白浪費幾千萬筆無意義的硬碟空間。因此，我們讓數據直接在記憶體中像無線電波一樣廣播，接收端畫出畫面後立即釋放，既省流量又做到極致順暢！

3. 多人即時同步核心：運作秘密大解密

很多學員好奇：「為什麼兩台設備之間的游標能像面對面一樣同步飛舞？」其核心運作包含三大步驟：

📐

1. 座標歸一化 (0~1)

不同學員的螢幕解析度不同（桌機 4K vs 手機 1080P）。我們將滑鼠點位轉換為比例 x = mouseX / width，確保在任何設備上位置分毫不差。

⚡

2. 極小操作電報

絕不傳輸畫面錄影！只廣播動作指引（例如 { action: "DROP", volume: 0.05 }，僅 40 Bytes），各端電腦各自計算化學反應。

〰️

3. 平滑插值 (LERP)

遠端游標透過數學線性插值計算：x += (targetX - x) * 0.25，即使網路稍有波動，夥伴的游標依然絲滑柔順、絕不閃爍跳動。

4. 跨帳號/跨裝置突破：從沙盒隔離到雲端 Secure WebSocket

在我們進行實戰測試時，常有學員遇到一個極其關鍵的痛點：

⚠️
學員實測疑問：
「老師，為什麼在同一個 Chrome 帳號開兩個分頁連線非常順暢，但一旦我換用另一個 Google 帳號、開啟無痕視窗，或是丟給隔壁同學用手機開啟，雙方就完全看不到彼此的游標與動作了？」

🔍 深度解密：為什麼 BroadcastChannel 無法跨帳號？

這是現代瀏覽器一項非常重要的資安架構——「同源沙盒隔離機制（Same-Origin Sandbox Isolation）」：

  • BroadcastChannel 是瀏覽器為同一個使用者設定檔（Profile）設計的高速內部通訊通道。
  • 當你開啟「無痕視窗（Incognito）」或切換到「另一個 Google 帳號 Profile」時，瀏覽器會為其分配完全隔離的獨立記憶體沙盒，任何本地通道都無法穿透這層物理防禦。
  • 至於不同電腦或手機，彼此之間更是隔著茫茫網際網路，本地的廣播通道自然無法跨網觸達。

🚀 破局方案：雙層傳輸體系 (MQTT over Secure WebSocket)

為了解決跨帳號障礙，同時堅守「零伺服器維護成本、免 API Key 申請」的初衷，我們將 RealtimeSync.js 升級為雙層同步體系：

🌐 OmniLab 雙層傳輸架構圖：

[使用者 A (Chrome 帳號 1)]  ──┐
                               ├──► 【全球開放 MQTT Broker: wss://broker.emqx.io:8084/mqtt】
[使用者 B (Chrome 帳號 2)]  ──┤     (訂閱頻道: antigravity/omnilab/room_{roomId})
                               │     ▲
[使用者 C (手機 / 遠端筆電)] ──┘     │
                                     ▼ (即時雙向廣播 20~40ms)
                        [所有連線成員同時同屏繪製！]
                        -------------------------------------------------
                        保底備援：若無外網，自動降級為本機 BroadcastChannel

技術亮點：採用標準 MQTT 協議（發布/訂閱模型）。使用者進入房間時自動訂閱該房間的主題；只要兩個人使用相同的房間代號（Room ID），無論身在何處或使用什麼帳號，都能毫秒級看見對方的科學家游標與操作！

5. 如何下提示詞：引導 Antigravity 四階漸進指揮術

在面對「60 FPS 動態渲染 + 跨網即時同步 + 多模組外掛」這樣龐大的專案時，如果只下單純的一句話「幫我寫一個物理化學實驗室」，AI 很容易生成出塞在單一檔案裡的巨大代碼。身為指揮官，我們要引導 Antigravity 依循「四階段漸進式提示詞」完成建造：

第一階段 Prompt：規劃外掛註冊架構與目錄規範

系統底座

指令目的：要求 AI 採用模組化設計，先建立「實驗室註冊中心（LabRegistry）」與「核心渲染循環（LabEngine）」。

引導指令：架構與外掛中心 
我想製作一個純前端的「多人即時在線物理化學實驗室（OmniLab）」，請幫我規劃可無限擴充的外掛式架構：
1. 採用原生 ES Module，不要使用任何打包工具。
2. 設計一個「LabRegistry」模組註冊表，所有實驗室都必須符合統一介面（id, name, init, update, render, onRemoteAction, destroy）。
3. 建立「LabEngine.js」處理 60 FPS 物理循環、高清 Canvas 適應，以及在上層繪製遠端夥伴的幽靈游標。
4. 請先建立核心目錄結構與基礎檔案骨架。

第二階段 Prompt：開發首發雙實驗室（化學滴定與萬有引力）

科學演算法

指令目的：明確告知 AI 化學平衡式、指示劑變色規則，以及牛頓萬有引力與克卜勒軌道預覽演算法。

引導指令：雙實驗室演算法 
請依據 LabRegistry 規範實現兩個外掛實驗室：
1.『exp1-titration.js』酸鹼滴定實驗：
  • 包含滴定管、旋塞、反應燒杯與磁力攪拌器漩渦動畫。
  • 依據已加 NaOH 毫升數真實計算 pH 值；支援酚酞（無色突變粉紅）與廣用指示劑。
  • 右側即時繪製 pH 滴定突躍 S 型曲線圖表；旋塞動作透過 sync.broadcastAction 同步給夥伴。
2.『exp2-gravity.js』萬有引力天體沙盒：
  • 牛頓萬有引力多體運動；支援投放行星、恆星與黑洞。
  • 滑鼠拖曳時，即時虛線計算並預覽未來 120 步的克卜勒公轉軌跡，且廣播給房間內其他夥伴看見！

第三階段 Prompt：打造響應式高科技 UI 與動態底部工具列

介面與體驗

指令目的：建立深色玻璃擬態的頂部控制條與底部浮動控制面板，當切換實驗室時，底部按鈕會依當前實驗動態重構。

引導指令：動態工具列與介面 
請完善 labs/index.html 與 CSS 介面：
1. 頂部提供發光的實驗室分頁切換按鈕，點擊切換時動態更換底部的浮動控制工具列。
2. 滴定實驗時，底部顯示「單滴、慢滴、快滴、關閉、切換指示劑、重置」。
3. 引力實驗時，底部切換為「行星、恆星、黑洞、太陽系預設、清空宇宙」。
4. 提供「雙分頁同步測試」按鈕，點擊自動彈出右側半螢幕子視窗便於學員實測。

第四階段 Prompt（突破瓶頸）：升級跨帳號/跨裝置雲端即時連線

跨網升級

指令目的：當發現 BroadcastChannel 無法跨帳號時，精準指示 AI 引入免金鑰的公網 WebSocket MQTT 協議，並建立房間切換與邀請複製功能。

引導指令：跨帳號與雲端 WSS 升級 
我實測後發現：同一帳號分頁能連線，但換成不同 Google 帳號或無痕視窗就無法在同一個房間！
請幫我將 RealtimeSync.js 升級為「支援跨帳號、跨瀏覽器、跨裝置」的雙層傳輸體系：
1. 引入免金鑰的公網 Secure WebSocket（例如 MQTT Broker: wss://broker.emqx.io:8084/mqtt），並保留 BroadcastChannel 作為本機保底。
2. 加上訊息去重機制，防止本機與雲端重複派發相同動作。
3. 在頁面上方加入「連線狀態燈」（顯示 🟢 雲端跨網 / 🟡 本地同源 / ⚪ 連線中）。
4. 支援自訂暱稱、點擊切換房間代號，並提供「🔗 複製邀請連結」按鈕，帶有 ?room=xxx 參數，讓任何人點擊網址就能加入同一個實驗室同屏協同！

跟著上述四階段步驟完成後，我們獲得了一套真正達到全球跨網同屏協同的現代化線上實驗室：

🧪 🌌 👥 🌐

OmniLab 線上實驗室實機運行已就緒！

點擊下方按鈕啟動實驗室。進入後，點擊頂部「🔗 複製邀請」，你可以：

雙方將在幾毫秒內看到彼此的彩色發光游標與動作即時同步！

7. 10 分鐘無限擴充新實驗室：複製外掛模板即可啟用！

因為我們在一開始就設計了 `LabRegistry` 外掛機制，未來無論你想做什麼新實驗（例如「串並聯電路實驗室」或「光學透鏡折射實驗室」），只要照著以下 3 步即可無痛擴充：

🛠️ 擴充新實驗室三步驟：

  1. 複製模板檔案：打開專案中的 labs/js/experiments/exp-template.js，另存為你的新檔案（例如 exp3-circuit.js）。
  2. 填入生命週期代碼：在 update(dt) 寫物理運算、在 render(ctx) 畫電路儀表、在 onRemoteAction 同步開關狀態。
  3. 在 index.html 引入：只需在 labs/index.html 開頭加上一行 import "./js/experiments/exp3-circuit.js";，頂部選單便會自動長出按鈕，開箱即用！
