第 6 章 · 全端自動化實戰

實戰串接 GAS：打造預購資料庫與自動寄發確認信

不用寫一行程式碼！本章帶你掌握「資料庫欄位規劃」思維，並運用精準的提示詞（Prompt），引導 Antigravity 同時寫好後端 GAS 雲端腳本、自動化 Gmail 寄信模板，以及前端網頁表單串接！

6-1 資料庫思維：Google 試算表（Excel）欄位該如何規劃？

很多初學者在做表單時，往往直接抓起試算表隨便填。在軟體工程中，「資料庫結構規劃（Schema Design）」是最關鍵的第一步！

為我們的「SmartSound Pro 耳機早鳥預購」，我們需要規劃以下 6 個標準資料欄位：

📋 推薦的預購表單欄位架構（第一列標題）：

欄位名稱 欄位英名 (Key) 資料類型 欄位目的與說明
時間戳記 timestamp 日期時間 記錄客戶下單的確切時間（由系統自動填入）。
客戶姓名 name 文字 稱呼客戶，寄確認信時用作稱謂（如「王大明 您好」）。
電子信箱 email Email 格式 重要！寄發預購成功通知信的目標收件地址。
聯絡電話 phone 文字 供後續物流出貨與簡訊通知使用。
預購方案 plan 選項 標記客戶選擇的「標準版」或「旗艦降噪版 Pro」。
備註需求 notes 長文字 客戶填寫的額外收件備註或需求。

6-2 動口不動手：讓 AI 生成 Excel 表格，一鍵上傳 Google 雲端轉為試算表

千‧萬‧不‧要手動打開表格一個個去打字、排版！身為 AI 時代的開發者，所有的資料庫範本同樣直接讓 Antigravity 幫我們生成 Excel 檔！

💬 提示詞：請 Antigravity 替我建立預購名單 Excel 表格範本
"Antigravity，請幫我建立一個名為『preorder_database_template.xlsx』的 Excel 表格檔案。
第一列請幫我放好 6 個標準資料庫欄位標題：『登記時間』、『客戶姓名』、『電子信箱』、『聯絡電話』、『預購方案』、『備註留言』，並在第二列附上一筆標準範例資料供參考！"

送出提示詞後，Antigravity 就會在你的專案目錄下生成 preorder_database_template.xlsx。接下來只要透過瀏覽器完成三步轉移：

三步搞定雲端資料庫

上傳 Google 雲端硬碟並轉為 Google 試算表

  1. 拖曳上傳： 開啟你的 Google 雲端硬碟 (Google Drive)，將剛才生成的 preorder_database_template.xlsx 直接拖曳上傳。
  2. 用試算表開啟： 在雲端硬碟點兩下打開該檔案，點選上方 「使用 Google 試算表開啟」。
  3. 另存為 Google 試算表（關鍵一步！）： 點選左上角 檔案 ➔ 「另存為 Google 試算表」。
    ✔ 此時你的 Excel 檔就正式轉換為具備完整雲端程式碼功能的 Google 試算表了！
  4. 開啟後端介面： 點選頂部選單 「擴充功能」 ➔ 「Apps Script」，直接進入雲端開發環境！

6-3 核心重點：向 Antigravity 下提示詞，生成 GAS 後端與自動寄信程式

現在我們要讓 Antigravity 替我們寫出接收資料、寫入試算表、並透過 Gmail 發送確認信的完整 GAS 程式碼。

💬 提示詞 1：向 Antigravity 索取 GAS 後端自動化腳本
"Antigravity，請幫我寫一段完整的 Google Apps Script (GAS) 程式碼。

【功能需求】：
1. 建立 doPost(e) 函數接收前端傳送的 POST 請求（JSON 格式）。
2. 需解析出 name, email, phone, plan, notes 五個欄位。
3. 將當前時間與這 5 個欄位，自動寫入（appendRow）到當前試算表的第一個工作表中。
4. 【自動寄送確認信】： 使用 GmailApp.sendEmail()，自動寄一封排版美觀的 HTML 郵件給客戶的 email。
- 信件主旨：『【SmartSound Pro】預購成功通知！感謝您的支持』
- 信件內容：帶入客戶姓名、預購方案、感謝詞，並告知出貨前會再通知。
5. 設定跨網域（CORS）保護，回傳 JSON 成功狀態給前端。
請提供整段程式碼，並在關鍵地方加上新手能看懂的中文註解！"

Antigravity 會立刻為你產出包含 doPost 與 GmailApp.sendEmail 的標準程式碼。你只需要全選複製，貼到 Google Apps Script 編輯器中，按下上方的 「儲存（磁碟片圖示）」 即可！

6-4 發布為 Web App 並取得專屬 API 網址

程式碼存檔後，必須將它發布為全世界可訪問的公開窗口：

  1. 點選右上角的藍色按鈕 「部署（Deploy）」 ➔ 「新增部署作業（New deployment）」。
  2. 左側齒輪圖示選擇 「網路應用程式（Web App）」。
  3. 關鍵權限設定（新手最常錯在這裡！）：
    • 執行身分（Execute as）： 選擇 我（你的帳號）。
    • 誰可以存取（Who has access）： 務必選擇 所有人（Anyone）（這樣訪客才能不用登入就提交表單）。
  4. 點選「部署」，並在彈出的權限確認視窗中允許存取你的 Google 試算表與 Gmail。
  5. 複製畫面產生的 「網路應用程式網址（Web App URL）」（以 https://script.google.com/macros/s/.../exec 結尾）。這就是你的後端 API！
⚠️
【觀念大解密：前端 GitHub vs 後端 GAS 部署差異】
很多學生改完程式後常常納悶：「為什麼我的修改沒有生效？」請務必牢記兩者的不同：
  • 前端網頁（HTML / CSS / JS）：
    改完之後，只要對 Antigravity 說「幫我推送到 GitHub」，Git Push 完成後 GitHub 就會自動重新部署，1~2 分鐘後線上網頁自動更新！
  • 後端 Google Apps Script (GAS)：
    GAS 無法從本機自動上傳！ 每次只要請 AI 改了 GAS 程式碼：
    ① 必須手動全選複製，貼進 Google 的 Apps Script 網頁編輯器。
    ② 按下「儲存（磁碟片圖示）」。
    ③ 最重要的一步（漏掉絕對沒效！）： 點右上角 「部署」 ➔ 「管理部署作業」 ➔ 點鉛筆圖示編輯 ➔ 版本選「新版本 (New version)」 ➔ 按下「部署」！
    （原因：如果沒有建立「新版本」，你的 Web App 網址將永遠停留在舊版的程式碼！）

6-5 關鍵連線：將第 2 章網頁與 GAS 真正對接

拿到 https://script.google.com/macros/s/.../exec 這串 API 網址後，這就是前端網頁把訂單送到試算表的「雲端橋樑」！

學員不需要去網頁程式碼裡搜尋是哪一行，只要直接把這句提示詞貼給 Antigravity：

💬 提示詞 2：請 Antigravity 將真實 GAS 網址接入第二章網頁
"Antigravity，我已經拿到我的 Google Apps Script Web App 網址：
https://script.google.com/macros/s/【請替換為你的實際網址】/exec

請幫我檢查並修改第二章的產品網頁 product-demo.html：
1. 將預購表單送出的 JavaScript 邏輯，改為真實呼叫上述 GAS 網址（使用 fetch(API_URL, { method: 'POST', body: JSON.stringify(...) })）。
2. 送出中將按鈕變更為『正在寫入雲端試算表並寄送確認信...』，防止連續重複點擊。
3. 當 GAS 回傳成功後，彈出提示視窗：『🎉 預購成功！確認信已自動發送至您的 Email，請查收！』並清空所有輸入框。
4. 幫我處理好 CORS 跨網域傳輸，確保在任何瀏覽器送出都不會被擋！"
💡
Antigravity 會自動完成： AI 會自動打開 product-demo.html，找到 form.addEventListener('submit') 區塊，把你的真實 GAS URL 填入，並加入完整的異步 fetch() 傳輸腳本！

6-6 享受奇蹟時刻：全端串接實測驗收與自動寄信

接好之後，用瀏覽器打開 product-demo.html，立刻親自下第一筆測試訂單：

🎉 完整驗收三部曲：

  1. 第 1 步 · 網頁填表送出： 在網頁底部輸入你的真實姓名、真實 Email、電話，選擇方案並按「送出預購登記」。
  2. 第 2 步 · 試算表即時記帳： 切換到你的 Google 試算表，你會親眼目睹第一列下方瞬間自動多出一行新的訂單資料，包含確切時間戳記！
  3. 第 3 步 · 手機叮咚！Gmail 自動寄達確認信：
    打開你的手機或 Gmail 收件匣，一封主旨為『【SmartSound Pro】預購成功通知！感謝您的支持』的精美確認信已經安靜地躺在信箱中：
    親愛的 王小明 您好：

    感謝您預購 SmartSound Pro 頂級降噪無線耳機（旗艦降噪版 Pro）！
    我們已收到您的早鳥登記資料。商品正式出貨前，我們將透過電話與信箱再次向您發送物流單號。

    SmartSound Pro 團隊 敬上

🚀 最後一步：使用第 4 章的 CLI 一鍵更新到 GitHub Pages！

測試成功後，只要對 Antigravity 說：

"Antigravity，請幫我執行 git add、commit（標題：feat: 串接 Google 試算表與自動寄信），並使用 gh 推送到 GitHub，更新我們的 GitHub Pages 線上網址！"

幾秒鐘之內，全世界上任何拿到你網址的朋友，點開你的網站填寫表單，都能真正自動寫入你的試算表並收到專屬確認信！
